# Warehouse Management System — Frontend

## Project Description
The Warehouse Management System is a web-based application developed to provide a user-friendly interface for warehouse operations and inventory management.

## Technologies Used
- React
- Vite
- JavaScript
- CSS
- Node.js and npm

## Prerequisites
- Node.js
- npm
- Git

## Installation and Execution

### 1. Clone the Repository
```bash
git clone https://github.com/veeradurgadeva-stack/warehouse-frontend.git
```

### 2. Navigate to the Project Folder
```bash
cd warehouse-frontend
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start the Development Server
```bash
npm run dev
```

### 5. Open the Application
Open the local URL displayed in the terminal. The default Vite URL is usually:

`http://localhost:5173`

## Project Objective
To provide a simple and user-friendly web interface for warehouse operations and inventory management.
